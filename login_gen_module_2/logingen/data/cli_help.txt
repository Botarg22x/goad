LOGINGEN — СБОР ФИО И E-MAIL

Использование: logingen (--domain DOMAIN --company NAME | -u URL|FILE) [ПАРАМЕТРЫ]

# ==================== ОСНОВНОЕ ====================

logingen --domain example.ru --company 'Пример'   Пассивный поиск
logingen -u https://example.ru                    Активный обход сайта
logingen -u urls.txt -g                           Сбор и генерация логинов

Тот же запуск: goad logins ...
Без -g сохраняются только найденные ФИО и e-mail; найденный адрес не
обязательно является действующим логином.

# ==================== ПАССИВНЫЙ СБОР ====================

--domain DOMAIN                    Почтовый домен, с @ или без
--company NAME                     Название организации для поиска ФИО
-s, --search-engine yandex,google  Поисковики; по умолчанию оба
--email-source search              Источник e-mail
--people-source search,setka        Источники ФИО
--setka-max-pages N                Ограничить обход Сетки
--search-delay SECONDS             Пауза между поисковыми запросами; обычно 10 с

По умолчанию ищутся почты в Google и Яндексе, ФИО в Сетке и найденных
документах. Сам сайт не обходится; документы из выдачи могут скачиваться.

# ==================== АКТИВНЫЙ СБОР ====================

-u, --url URL|FILE                 Начальный адрес или файл адресов
--katana-depth N                  0/1 — старт; 2 — также ссылки со старта
--max-pages N                     Общий предел HTML-страниц; обычно 20
--allowed-domain DOMAIN           Область обхода
--browser-crawl                   Отрисовать все страницы в браузере

Katana обходит сайт и передаёт страницы на анализ ФИО, e-mail и документов.
Для пустых JS-страниц браузер включается автоматически. Поисковики и Сетка
в активном режиме по умолчанию выключены.

# ==================== ДОКУМЕНТЫ И ГЕНЕРАЦИЯ ====================

--no-documents                   Не скачивать документы
--document-types pdf,docx,pptx   Ограничить форматы; по умолчанию все доступные
--max-documents N                Предел документов на источник
-g, --generate                  После сбора выбрать шаблон и создать кандидатов
--person-pattern PATTERN         Свой шаблон, например '{f}.{lastname}'
--kind login|email|both          Формат без интерактивного выбора
--limit N                        Предел сгенерированных кандидатов

Поддерживаются PDF, DOCX, PPTX, XLSX, ODT, ODP, ODS, TXT и CSV.
С -g найденные e-mail идут перед сгенерированными вариантами.

# ==================== СЕТЬ И РЕЗУЛЬТАТ ====================

--slow                           Пауза не меньше 15 с между запросами
--request-delay SECONDS          Своя пауза
--proxy URL                      HTTP-прокси
--ca-cert FILE                   CA для HTTPS через прокси
--user-agent TEXT                Свой User-Agent; по умолчанию Chrome/Linux
-o, --output-dir DIR             Папка результатов; обычно output/ДОМЕН/
--save-artifacts                 Сохранить страницы, документы, пруфы и журнал
-v, --verbose                   Подробная статистика
-h, --help                      Показать эту справку

Результат: fio.txt и emails.txt; с -g дополнительно logins.txt.
Пример: logingen --domain example.ru --company 'Пример' --slow --save-artifacts
