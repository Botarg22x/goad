# logingen — сбор ФИО, почт и генерация логинов

Основной способ работы — отдельная утилита `logingen`. Обёртка
`goad logins` принимает те же параметры. `goad run` остаётся
дополнительным способом связать несколько модулей.

## Установка

Из каталога `login_gen_module_2`:

```bash
python3 -m pip install -e '.[browser,documents]'
python3 -m playwright install chromium
logingen -h
```

Для активного сбора нужна установленная Katana в PATH либо параметр
`--katana-executable /путь/к/katana`. Для пассивного сбора Katana не нужна.

## Пассивный сбор

```bash
logingen --domain @example.ru --company "Пример"
```

По умолчанию включены Google и Яндекс, документы из поисковой выдачи и ФИО
из Сетки. Почтовый домен допускается с @ и без него. Сайт не обходится;
найденные документы скачиваются с серверов, где они размещены, включая
сайт компании. Полученные почты не считаются подтверждёнными учётными записями.

Гибкая настройка:

```bash
logingen --domain example.ru --company "Пример" -s google --setka-max-pages 2 --slow
logingen --domain example.ru --company "Пример" --email-source search --no-documents
logingen --domain example.ru --company "Пример" --people-source setka
```

Если заданы источники через `--email-source`/`--people-source`, используются
только перечисленные источники. Имена принимаются через запятую и повторением.

## Активный сбор

```bash
logingen -u https://example.ru --katana-depth 2 --max-pages 30 --slow
logingen -u addresses.txt --katana-depth 1 -o results/active
```

Файл UTF-8 содержит по одному HTTP(S) URL, домену или IP на строку.
Пустые строки и строки с # пропускаются; без схемы выбирается HTTPS.
Katana получает страницы, модуль извлекает ФИО/почты и разбирает документы.
Каждая страница загружается Katana на глубине 1, а очередь переходов и общий
лимит страниц ведёт модуль. Это позволяет сохранять результаты после каждой
страницы и ограничивать обход нескольких стартовых сайтов вместе.

`--katana-depth 0` и `1` обрабатывают только стартовые страницы;
`2` добавляет найденные на них HTML-ссылки. Документы со страниц последнего
уровня тоже разбираются. JS-оболочки автоматически передаются headless-браузеру.
`--browser-crawl` принудительно отрисовывает страницы.

Поисковики и Сетка в этом режиме по умолчанию отключены. Их можно добавить:

```bash
logingen -u https://example.ru --domain example.ru --company "Пример" -s yandex,google --setka
```

## Результаты и генерация

Без дополнительных флагов: `output/ДОМЕН/fio.txt` и `emails.txt`.
`-o DIR` выбирает общую папку. Находки сохраняются по ходу сбора,
включая сохранение уже полученного при Ctrl+C.

```bash
logingen --domain example.ru --company "Пример" -g -o results/example
```

`-g` открывает выбор шаблонов и конечного формата после сбора. Перед выбором
видны число найденных ФИО и найденные почты. В `logins.txt` сначала идут
найденные e-mail, затем сгенерированные кандидаты; дубликаты удаляются.
`fio.txt` и `emails.txt` по-прежнему содержат только находки.

Неинтерактивный вариант:

```bash
logingen -u https://example.ru --domain example.ru -g --person-pattern '{f}.{lastname}' --kind email --no-pattern-prompt
```

`--save-artifacts` включает документы, копии страниц, подробный журнал,
JSONL, CSV и Excel со ссылками на источники. Без него промежуточные документы
и страницы используются во временном каталоге, который удаляется после запуска.
Явные пути диагностики также включают сохранение для совместимости.

## Документы и скорость

Поддерживаются PDF, DOCX, PPTX, XLSX, ODT, ODP, ODS, TXT, CSV. PDF использует
pdfminer.six; офисные XML-форматы разбираются без установленного Office.
Старые бинарные DOC/PPT/XLS и OCR сканированных изображений не поддерживаются.

```bash
logingen --domain example.ru --company "Пример" --document-types pdf,docx,pptx --max-documents 5
logingen -u https://example.ru --no-documents --slow
```

`--slow` задаёт паузу не менее 15 секунд между открытиями страниц и документами;
`--request-delay N` задаёт свою паузу. Katana обрабатывает одну страницу за раз,
с ограничением не более одного запроса в секунду. Ресурсы браузерной страницы
регулируются отдельно от этих открытий. У Сетки минимальная пауза 15 секунд.
`--max-documents` ограничивает документы отдельно для сайта и поисковой выдачи.

Русская справка хранится в `logingen/data/cli_help.txt`.

## Проверка

Из каталога `login_gen_module_2`:

```bash
python3 -m pytest tests -q
```

Тест Katana использует временный локальный HTTP-сервер. Пассивные источники
проверяются на сохранённых/синтетических ответах без запросов во внешнюю сеть.
