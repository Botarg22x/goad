# GOAD CLI

This package provides the `goad` command. The four modules can also be run
independently as `passgen`, `logingen`, `pointfinder`, and `authchecker`.

Start with the [workspace README](../README.md) for installation and the
recommended workflow. Run `goad -h` for a short overview, or use
`goad passwords -h`, `goad logins -h`, `goad discover -h`, `goad check -h`, and
`goad run -h` for module-specific options.

The Russian help texts are separate editable files in `src/goad/`.
