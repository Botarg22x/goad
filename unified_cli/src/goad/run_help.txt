GOAD RUN — ДОПОЛНИТЕЛЬНЫЙ ЗАПУСК ЦЕПОЧКИ

Использование: goad run ЦЕЛЬ ЭТАПЫ [ПАРАМЕТРЫ]

# ==================== ОСНОВНОЕ ====================

goad run -u URL --collect-points             Найти точки входа
goad run -u URL --collect-logins             Собрать ФИО и e-mail
goad run -u URL -l ЛОГИН -p ПАРОЛЬ           Найти точку и проверить вход
goad run -q -u URL -p passwords.txt --slow   Быстрый полный пресет

Этапы можно объединять. Без пароля попытки входа не выполняются.
Для раздельного запуска используйте goad passwords/logins/discover/check.

# ==================== ЦЕЛЬ И ЭТАПЫ ====================

-u, --url URL                  Сайт для сбора и поиска точек
--discovery-file FILE          Список URL, доменов или IP для поиска
--target URL                   Одна уже известная страница входа
--login-pages-file FILE        Готовые страницы входа, по URL на строку
--collect-logins               Сбор ФИО и e-mail
-g, --generate                После сбора создать варианты логинов
--collect-points               Поиск точек входа: Katana и стандартные пути
--page-only                    Проверить только стартовые страницы, без обхода ссылок
--discover-only                Найти точки без попыток входа
-q, --quick                   Сбор, генерация, Subfinder, Katana и пути

# ==================== НАСТРОЙКА ПОИСКА ====================

--subfinder                    Добавить найденные поддомены
--katana                       Обойти страницы сайта
--standard-path                Проверить типовые адреса входа
--no-standard-paths            Отключить проверку типовых адресов
--nmap                         Дополнительно проверить сетевые службы
--katana-depth N               0/1 — старт; 2 — также ссылки со старта
--katana-max-total-pages N     Общий предел страниц Katana
--mail-domain DOMAIN           Почтовый домен для внешнего поиска
--company NAME                 Название организации для поиска ФИО
--search-engine yandex,google  Выбрать поисковики
--email-source site,search     Источники e-mail
--people-source site,search,setka  Источники ФИО
--no-documents                 Не скачивать документы

# ==================== ПРОВЕРКА И СКОРОСТЬ ====================

-l VALUE|FILE                  Логин или файл; можно повторять
-p VALUE|FILE                  Пароль или файл; можно повторять
--slow | --normal | --fast      Скорость всех включённых этапов; normal по умолчанию
--rate N                       Скорость попыток входа, запросов/с; обычно 1
--threads N                    Параллельные попытки; обычно 1
--max-per-account N            Предел на точку и логин; по умолчанию 3
--max-total N                  Общий предел попыток на URL
--proxy URL                    HTTP-прокси для сетевых этапов
--ca-cert FILE                 CA для проверки HTTPS через прокси
--user-agent TEXT              Свой User-Agent; по умолчанию Chrome/Linux

При проверке входа сначала используется HTTP. Если нужны JavaScript, cookies
или CSRF, браузер подключается автоматически и работает без видимого окна.

# ==================== РЕЗУЛЬТАТ ====================

-s DIR                         Папка результатов; по умолчанию ./artifacts
-v, --verbose                  Подробности в консоли; run.log пишется всегда
--json                         JSON вместо коротких строк
-y, --yes                      Не задавать интерактивные вопросы
-h, --help                     Показать эту справку

Пример: goad run -u https://example.ru --collect-logins --collect-points --subfinder -p passwords.txt --slow
Работайте только с системами, на проверку которых у вас есть разрешение.
