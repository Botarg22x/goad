- Добавить обязательный паттерн генерации; флаг можно повторять: -p <PATTERN>, --pattern <PATTERN>.
- Подключить словарь PATH под именем NAME; флаг можно повторять: --wordlist <NAME> <PATH>.
- Соединять две именованные словарные переменные построчно вместо перебора всех сочетаний; флаг можно повторять для непересекающихся пар: --zip-wordlists <NAME1,NAME2>.
- Подключить словарь альтернативной записью в одном аргументе; флаг можно повторять: --wordlist <NAME=PATH>.
- Пропускать в словаре NAME слова короче N символов: --wl-min-length <NAME> <N>.
- Пропускать в словаре NAME слова длиннее N символов: --wl-max-length <NAME> <N>.
- Прочитать из словаря NAME не больше N физических строк или все строки при значении all: --wl-max-lines <NAME> <N|all>.
- Использовать для словаря NAME указанную кодировку: --wl-encoding <NAME> <ENCODING>.
- Оставить только строки словаря NAME, содержащие категорию digits, lowercase, uppercase или special: --wl-require <NAME> <CATEGORY>.
- Исключить строки словаря NAME, содержащие категорию digits, lowercase, uppercase или special: --wl-forbid <NAME> <CATEGORY>.
- Создать именованный набор символов NAME для использования в паттерне как ?{NAME}: --charset <NAME> <CHARACTERS>.
- Задать пользовательский набор символов ?1: --charset1 <CHARACTERS>.
- Задать пользовательский набор символов ?2: --charset2 <CHARACTERS>.
- Задать пользовательский набор символов ?3: --charset3 <CHARACTERS>.
- Задать пользовательский набор символов ?4: --charset4 <CHARACTERS>.
- Добавить мутации через запятую (включая append, prepend и replace); флаг можно повторять, а запятую внутри значения экранировать как \, : --mutation <RULE...>.
- Выбрать независимое или последовательное применение мутаций: --mutation-mode <independent|chained>.
- Включать исходный кандидат вместе с результатами мутаций; это поведение используется по умолчанию: --include-original.
- Не включать исходный кандидат в результаты мутаций: --no-include-original.
- Подключить файл с поддерживаемым подмножеством правил hashcat; флаг можно повторять: --rule-file <PATH>.
- Исключить готовые кандидаты короче N символов: --result-min-length <N>.
- Исключить готовые кандидаты длиннее N символов: --result-max-length <N>.
- Записать результат в PATH; значение - направляет кандидаты в stdout, путь по умолчанию candidates.txt: -o <PATH>, --output <PATH>.
- Использовать указанную кодировку выходного файла; значение по умолчанию utf-8: --encoding <ENCODING>.
- Атомарно заменить существующий output вместо объединения со старыми кандидатами: --force.
- Задать предельную оценку для неинтерактивного запуска без --yes; значение по умолчанию 1000000: --confirm-above <N>.
- Ограничить итоговый файл или stdout до N уникальных паролей с учётом уже сохранённых строк; при превышении старого файла нужен --force: --max-passwords <N>.
- Показать оценочный план до фильтров и дедупликации, затем завершить работу без генерации: --plan.
- Пропустить интерактивные подтверждения: --yes.
- Сохранить эквивалентную YAML-конфигурацию; без --plan после сохранения продолжить генерацию: --save-config <PATH>.
- Разрешить замену файла, указанного в --save-config; требует использования --save-config: --overwrite-config.
- Показать статистику после генерации: --stats.
- Показать версию passgen и завершить работу: --version.
- Показать только основную справку из файла password_generator/help/ru.yaml: -h, --help.
- Загрузить и запустить YAML-конфигурацию CONFIG; перед генерацией автоматически показать план: passgen from-config <CONFIG>.
- Проверить YAML-конфигурацию и паттерны без генерации и записи output: passgen from-config <CONFIG> --check.
- Показать оценочный план YAML-конфигурации и завершить работу без генерации: passgen from-config <CONFIG> --plan.
- Запустить YAML-конфигурацию без интерактивных подтверждений: passgen from-config <CONFIG> --yes.
- Атомарно заменить output из YAML вместо объединения со старыми кандидатами: passgen from-config <CONFIG> --force.
- Переопределить output.path из YAML-конфигурации: passgen from-config <CONFIG> -o <PATH>, passgen from-config <CONFIG> --output <PATH>.
- Показать статистику после генерации из YAML-конфигурации: passgen from-config <CONFIG> --stats.
- Показать только основную справку из файла password_generator/help/ru.yaml: passgen from-config -h, passgen from-config --help.
