# Локальный стенд WordPress

Файлы стенда находятся в папке `wordpress` проекта. Из этой папки:

```bash
sudo docker compose up -d
sudo docker compose ps
```

Откройте http://127.0.0.1:8081 и завершите установку WordPress в браузере.
Доступ к стенду открыт только с этого компьютера.

Данные сайта и MySQL хранятся в именованных томах Docker и сохраняются при
`sudo docker compose down`. Это сделано потому, что папка проекта находится на
NTFS, где размещать рабочие файлы MySQL ненадёжно. Для копии данных прямо в
папку проекта выполните:

```bash
sudo bash backup.sh
```

Копии появятся в `wordpress/backups/`: база в `wordpress.sql`, содержимое сайта
(темы, плагины, загрузки) в `wp-content.tar.gz`. Перед переносом проекта
создайте такую копию: именованные тома Docker не переносятся вместе с папкой.

Чтобы остановить стенд без удаления данных:

```bash
sudo docker compose down
```
