AUTHCHECKER — ПРОВЕРКА ВХОДА

Использование: authchecker (-u URL|FILE | -r REPORT.json) -l LOGIN|FILE -p PASSWORD|FILE [ПАРАМЕТРЫ]

# ==================== ОСНОВНОЕ ====================

authchecker -u auth-links.txt -l admin -p passwords.txt --slow
authchecker -u https://example.ru/login -l admin -p 'пароль'
authchecker -r report.json -l users.txt -p passwords.txt --max-per-account 2

Тот же запуск: goad check ...
-u принимает готовую страницу входа или TXT-файл URL; обход сайта здесь
не выполняется. Для поиска страниц сначала запустите goad discover.

# ==================== ПАРАМЕТРЫ ====================

-u URL|FILE               Готовая страница входа или файл URL
-r REPORT.json           Отчёт PointFinder вместо списка ссылок
-t PRODUCT               Проверить страницу по шаблону продукта
-l VALUE|FILE            Логин или файл логинов
-p VALUE|FILE            Пароль или файл паролей
--slow                   Одна попытка в 15 с, один поток
--rate N                 Попыток в секунду; по умолчанию 1
--threads N              Параллельные попытки; по умолчанию 1
--max-per-account N      Предел на точку и логин; без флага явного предела нет
--max-total N            Общий предел попыток
--proxy URL              HTTP-прокси
--ca-cert FILE           CA для проверки HTTPS через прокси
--audit FILE             Журнал попыток без паролей
-h, --help              Показать эту справку

Успешная пара выводится сразу. Если сервер не дал явных признаков результата,
выводится «РЕЗУЛЬТАТ НЕ ОПРЕДЕЛЁН», а не ложный успех или отказ.

# ==================== ПОДРОБНЫЙ ЗАПУСК ====================

authchecker validate report.json          Проверить структуру отчёта
authchecker plan -h                      План без сетевых запросов
authchecker run -h                       Все настройки проверки

Работайте только с системами, на проверку которых у вас есть разрешение.
